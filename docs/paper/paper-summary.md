# 논문 정리 — 2계층 하이브리드 협동 NPC

> **제목**: 보스 레이드 환경에서 행동 트리와 역할별 강화학습을 결합한 2계층 하이브리드 협동 NPC: 전투 의사결정과 기믹 수행의 분리 학습
> **저자**: 박준형 (서강대학교 가상융합전문대학원 메타버스 테크놀로지)
> **원문**: [main.tex](main.tex) (APA 7, XeLaTeX) · 상태: 초안 (사용성 평가 전)

## 1. 한 줄 요약

보스 레이드 파티원 NPC의 의사결정을 **"실패하면 즉시 전멸하는 이산적 기믹 → 행동 트리(규칙)"**와 **"맥락 의존적인 연속 전투 판단 → 역할별 PPO(학습)"**로 분리한 2계층 구조를 제안하고, 순수 RL이 30만 에피소드로도 못 해낸 기믹 보장을 유지하면서 2만 에피소드 학습만으로 규칙 기반 기준과 동등한 승률(70.8%)에 도달했다.

## 2. 문제 의식 (연구 동기)

- 보스 레이드 협동 기믹(전멸기 은신 등)은 ① 발생 빈도가 낮아 학습 신호가 희소하고, ② 전원 동시 성공을 요구하며, ③ 한 번 실패가 곧 에피소드 종료(전멸)다. → 순수 RL로 학습하기 구조적으로 어렵다.
- **사전 실험의 실패가 직접적 근거**: 동일 계열 환경에서 역할별 PPO를 단일 보상으로 약 30만 에피소드 학습 →
  - 기믹 수행이 끝까지 안정화되지 않음
  - 약 16만 에피소드 이후 정책 엔트로피 붕괴 → 성능 퇴행
  - 보상 재설계 8회 반복으로도 승률 56% / 무력화 기여 37%가 한계, 기믹의 결정론적 보장은 확보 실패
- 반대로 규칙 기반(FSM/BT)은 기믹은 보장하지만 설계자가 명시하지 않은 상황에서 경직되고 유지보수 비용이 크다.

**→ 핵심 설계 원칙: "이산적이고 규칙이 명확한 행동은 규칙으로, 연속적이고 맥락 의존적인 판단은 학습으로."**

## 3. 시스템 환경 (자체 제작 게임)

| 구성 | 내용 |
|---|---|
| 아키텍처 | Python 시뮬레이션 서버(전투 판정 권위) + Unity 6 클라이언트(렌더링·조작) |
| 통신 | 스냅샷 UDP 송신, 플레이어 명령 TCP 수신, 0.3초 이산 턴 |
| 이동 권위 분리 | 플레이어 이동은 클라이언트 권위(20Hz), 전투 판정은 서버 권위 |
| 보스 | FSM 제어, 패턴 11종(방향성 근접기·광역기·추격 돌진·카운터/패링 유도기·낙인·전멸기 등), 체력 75%/50% 페이즈 전환, 50%에서 전멸기 강제 발동, 상시 무력화 게이지, 체력 연동 축소 원형 전장 |
| 파티 | 실제 플레이어 1인(딜러) + NPC 3인(탱커·힐러·서포터) |
| 관측/행동 | 관측 132차원 벡터, 이산 행동 22종(8방향 이동·평타·역할 스킬·회피·카운터 등) |
| 학습 시 | Unity 없이 서버 헤드리스 구동 (실시간 제약 없음) |

## 4. 제안 방법: 2계층 하이브리드

### 제1계층 — 기믹 행동 트리 (결정론적)

매 턴 우선순위로 평가, 발화하면 행동 확정, 미발화 시 제2계층에 위임.

| 순위 | 규칙 |
|---|---|
| 1 | 전멸기 은신 → 최종 생존 기둥 뒤 시야 차단 지점 이동 |
| 2 | 임박 위험 회피 (위험 도형 안 ∧ 잔여 ≤ 2턴) → 최단 탈출, 탱커는 가드 |
| 3 | 낙인 산개 → 파티로부터 이격 |
| 4 | 무력화 집중 (보스 그로기) → 근접 집중 공격, 탱커는 도발 우선 |
| 5 | 패링 장판 탈출 (NPC는 패링 불가) |
| 6 | 돌진 유도 → 기둥 후방으로 이동해 충돌 유도 |

- 규칙은 **저빈도·고실패비용 기믹에만 한정**. 일반 포지셔닝/공격/회복은 의도적으로 미포함.
- 위험 잔여 3턴 이상이면 발화하지 않음 → "선제적 포지셔닝"은 RL 학습 대상으로 남김.

### 제2계층 — 역할별 독립 PPO

- 탱커·힐러·서포터 각각 독립 액터–크리틱 (은닉 2층 × 256유닛).
- 보상 = 팀 공통 항(보스 처치·파티 생존·시간 페널티) + 역할 항(탱커: 어그로 유지 / 힐러: 유효 회복·위급 대상 우선 / 서포터: 버프 적중·보조 딜).
- 위험 도형 안에서는 양(+)의 역할 보상 차단 → 회피 우선.
- **기믹 보상 전부 제거(combat_only)** — 기믹은 제1계층이 보장하므로 학습 신호가 명료해지고 탐색 공간이 축소.

### 준마르코프(semi-MDP) 표본 수집

- BT가 발화한 턴은 RL 학습 표본에서 **제외** (정책이 생성하지 않은 행동으로 정책 경사가 오염되는 것 방지).
- 해당 턴들의 보상은 **직전 RL 결정에 누적 귀속** → 하나의 RL 결정이 "다음 RL 결정까지의 구간"을 갖는 시간 확장 행동 (옵션 프레임워크와 동형).

### 학습 절차

1. **BC 웜스타트**: FSM 시연 2,000 에피소드로 교차 엔트로피 사전학습
2. **커리큘럼**: 보스 HP 12,000 → 28,000 → 55,000(실전), 최근 승률 40% 도달 시 승급
3. **플레이어 도메인 랜덤화**: 에피소드마다 공격형(회피 지연)·안정형(회피 우선)·미숙형(확률적 오행동) 성향 샘플링 + 이동 지터·스킬 지연 노이즈
4. **학습–배포 일치**: 배포 시 관측 1턴 지연 → 학습에서도 동일 지연 적용
5. **엔트로피 감시**: 역할별 엔트로피 로깅, 붕괴 시 체크포인트 롤백

**배포 시 인간성 장치**: 온도 1.0 확률적 샘플링(argmax 금지) + 직전 이동 방향 로짓 보너스(행동 관성, 지터 억제). 모델 부재 시 규칙 기반으로 폴백.

## 5. 결과 (학습 종료 후 최종 난이도, n=120)

| 지표 | 값 |
|---|---|
| **승률** | **70.8%** (규칙 기반 기준 64–75%와 동등) |
| 평균 처치 시간 | 754턴 ≈ 3.8분 (제한 1,300턴) |
| **기믹 성공률** | **86.9%** (학습 전 구간 85% 내외로 일정) |
| BT 발화 비율 | 전체 NPC 턴의 **21.8%** (78%는 RL이 결정) |
| 성향별 승률 | 공격형 82.2% / 안정형 71.8% / 미숙형 55.6% |
| 엔트로피 붕괴 | 미관찰 |
| 학습 비용 | BC 2,000 + PPO 20,000 에피소드, GPU 1기 약 12.6시간 (~26 ep/min) |

**핵심 관찰 3가지**
1. 기믹 성공률이 학습 초기부터 일정 → 기믹은 학습 산물이 아니라 제1계층의 결정론적 보장 (순수 RL 사전 실험과 가장 뚜렷한 대비).
2. 규칙은 병목 구간(22%)만 점유, 행동 다양성은 학습(78%)이 담당하는 분업 성립.
3. 미숙형 플레이어 승률이 학습 중반 0–33% → 최종 55.6%로 개선 → 성향 랜덤화가 의도한 강건성 형성.

## 6. 기여 (논문이 주장하는 것)

1. 기믹/전투 판단을 BT와 역할별 RL로 분리하는 2계층 구조 제안 + 실제 플레이 가능한 게임에 구현
2. BT 발화 턴 제외 + 보상 누적 귀속의 준마르코프 표본 수집으로 규칙 개입의 정책 경사 오염 문제 처리
3. 실제 플레이어 협동을 전제로 한 플레이어 성향 도메인 랜덤화
4. 순수 RL 실패 관찰을 포함한 설계 근거와 중간 지표 공개 → 후속 연구 기준점

## 7. 계획된 평가 (향후)

- **통제 비교**: 동일 조건에서 규칙 기반(A) vs 하이브리드(C) 각 수백 에피소드 — 가설은 우월성이 아닌 **비열등성**. 기대 이점은 미학습 조건 적응력과 인식된 협동 품질.
- **사용성 평가**: 실제 플레이어 대상 반복측정 설계(조건 교차 배치), 역할 수행도·협동성·신뢰도·예측 가능성·상황 적응성 리커트 측정 (Malle & Ullman 신뢰 척도 번안, Cronbach's α 확인). 객관 로그 지표와 주관 평가의 상관 분석 — 특히 행동 다양성 vs 예측 가능성 인식의 상충 여부.

## 8. 한계

1. 순수 RL 대조군(B)이 동일 환경 재학습이 아니라 동일 계열 사전 실험으로 갈음됨
2. 규칙 기반(A) 비교가 단일 평가 배치 기준 — 다중 시드 분산·통계 검정 미수행
3. 학습 중 플레이어가 스크립트 모델 — 실제 인간 행동 분포와의 간극은 사용성 평가로 확인 필요
4. 제1계층 규칙이 11개 패턴에 수동 설계 — 새 패턴 추가 시 규칙 갱신 비용 (규칙 계층 자동 구성이 후속 주제)
