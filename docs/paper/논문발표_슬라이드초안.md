## 슬라이드 2 — 연구 배경: 보스 레이드 파티원 NPC의 딜레마

- 보스 레이드 = 역할(탱커·딜러·힐러·서포터) 분담 + 협동 기믹 수행이 필수인 콘텐츠
- 파티원을 NPC로 대체하려는 수요는 크지만, 두 접근 모두 구조적 한계

**좌우 대비 박스:**

| 규칙 기반 (FSM/행동 트리) | 순수 강화학습 (PPO) |
|---|---|
| ✓ 필수 기믹은 확실히 보장 | ✓ 상황 적응·행동 다양성 확보 |
| ✗ 명시하지 않은 상황에서 경직 | ✗ 기믹: 저빈도·동시 성공·실패=전멸 |
| ✗ 규칙 수 폭발 → 유지보수 비용 급증 | ✗ 희소 보상 → 학습 신호 부족 |
| ✗ 플레이어 성향 변화에 미대응 | ✗ 기믹 실패가 전투 학습까지 오염 |

- **강조 문장**: → 성격이 다른 두 과제를 하나의 방식으로 처리하는 것 자체가 비효율

## 슬라이드 3 — 설계 근거: 순수 강화학습 사전 실험의 실패

- 동일 계열 보스 전투 환경에서 역할별 PPO를 단일 보상으로 약 30만 에피소드 학습
  - 협동 기믹(무력화 시간 창 대응 등) 수행이 학습 후반까지 안정화되지 않음
  - 약 16만 에피소드 이후 정책 엔트로피 붕괴 → 승률이 오히려 하락(퇴행)
  - 보상 재설계 8회 반복 → 승률 56%, 무력화 기여 37%가 한계
- **결론: 기믹의 결정론적 보장은 학습으로 확보되지 않았다**
- 교훈: "기믹 수행을 학습으로 획득"하는 비용 ≫ "기믹은 규칙으로 보장하고 학습은 전투에 집중"시키는 비용 → 2계층 분리 설계로 이어짐

## 슬라이드 4 — 핵심 아이디어: 실패 비용 기반 제어권 분리

행동을 구현 난이도가 아니라 **두 기준**으로 분류하여 제어 방식을 배정:

1. **실패 비용** — 행동 실패가 전투 결과에 미치는 영향 (전멸기 회피 실패 = 즉시 전멸)
2. **판단의 결정성** — 올바른 행동이 명확히 정의되는 정도 (전멸기 → 기둥 뒤 은신: 정답 명확)

| 행동 트리 (제1계층) | 역할별 PPO (제2계층) |
|---|---|
| 실패 비용 높음 + 정답 명확 | 실패 비용 낮음 + 맥락 의존 |
| 저빈도·탐색 어려움·동시 성공 필요 | 고빈도·반복 경험 가능·성향 적응 |
| 전멸기 은신 / 낙인 산개 / 임박 회피 / 돌진 유도 / 무력화 집중 | 포지셔닝 / 어그로 관리 / 회복 대상 / 버프 타이밍 / 선제적 위치 조정 |

- **강조**: 매 턴 BT 조건 평가 → 발화 시 행동 확정, 미발화 시 PPO에 위임 (제어권은 항상 한쪽에)

## 슬라이드 5 — 제안 시스템: 2계층 하이브리드 협동 NPC (구조도)

**다이어그램 (좌 → 우 흐름):**

- 왼쪽 열 (환경): 실제 플레이어 1인(딜러, Unity 클라이언트, 이동은 클라이언트 권위) / NPC 3인(탱커·힐러·서포터, 역할별 독립 정책) / 보스(FSM, 패턴 11종·페이즈 3단계·무력화 게이지·축소 전장)
- 가운데 열 (2계층): 제1계층 기믹 BT(우선순위 6규칙: 전멸기 은신·임박 회피·낙인 산개·무력화 집중·패링 장판 탈출·돌진 유도) → 미발화 시 아래로 위임 → 제2계층 역할별 PPO(은닉 2×256 액터-크리틱, 순수 전투 보상만 — 기믹 보상 전부 제거)
- 오른쪽 열 (출력): 행동 결정 — BT 발화 시 확정 행동, 미발화 시 PPO 샘플링. **BT는 전체 턴의 ~22%만 개입**
- 하단 캡션: Python 시뮬레이션 서버(0.3초 턴, 전투 판정 권위) + Unity 6 클라이언트 — 학습 시 헤드리스 구동

## 슬라이드 6 — 핵심 방법론: 규칙 개입 구간의 준마르코프 표본 처리

- 문제: 학습 중에도 BT가 활성 → 롤아웃에 "PPO가 안 고른 행동"이 섞임
  - PPO는 on-policy — BT 행동을 표본에 넣으면 정책 경사가 오염됨
- **해법: BT 개입 턴은 표본에서 제외하되, 보상은 버리지 않고 직전 PPO 결정에 할인 누적**

**수식 박스 (가변 길이 준마르코프 전이 — 옵션 프레임워크의 SMDP 구조 적용):**

$$\left(s_t,\; a_t,\; R_t^{(k)},\; s_{t+k}\right), \qquad R_t^{(k)} = \sum_{i=0}^{k-1} \gamma^i\, r_{t+i}$$

- k = 다음 PPO 결정까지의 턴 수 — 하나의 RL 결정이 "다음 결정까지 구간"을 책임짐
- BT 미개입 턴은 k=1로 퇴화 → 일반 PPO와 동일 (기존 이론과 정합)
- 주장 방식: SMDP를 새로 제안하는 것이 아니라, 규칙 개입 환경의 표본 오염 문제에 **적용**하는 것

## 슬라이드 9 — 결과 해석: 세 가지 관찰

1. **기믹 성공률이 학습 내내 일정 (85% 내외)** — 기믹 수행은 학습의 산물이 아니라 제1계층의 결정론적 보장에서 나옴. 30만 ep로도 불안정했던 순수 RL과 가장 뚜렷한 대비
2. **규칙 22% / 학습 78%의 분업 성립** — 규칙은 실패 비용이 극단적인 병목 구간만 점유, 행동 다양성은 학습이 담당. 이 분업 하에 규칙 기반과 동등한 승률 도달
3. **미숙형 플레이어 승률 0–33% → 55.6% 개선** — 피격 잦은 미숙형 조건에 힐러·서포터 정책이 적응. 성향 랜덤화가 의도한 강건성 형성의 증거

## 슬라이드 10 — 기존 연구와의 차별점

- 기존 BT–RL 결합 연구: 분리 기준이 행동 복잡도·스킬 종류·연산 부하 (예: 분산형 하이브리드, 김동주·고석주 2025)
  - **→ 본 연구: 실패 비용과 판단 결정성이 분리 기준, 규칙 개입 표본 처리를 명시적으로 다룸**
- 보스 레이드 RL 국내 연구: AI가 4인 파티 전체를 조종, 인간 플레이 모방 목표 (전준렬·홍진혁 2025)
  - **→ 본 연구: 실제 플레이어가 파티에 포함, NPC가 그와 협동 + 기믹의 결정론적 보장**
- 실드(Shielding) 계열: 위험 행동의 차단 ↔ 본 연구는 필수 협동 행동의 강제 + SMDP 귀속
- 역할 창발 MARL(ROMA 등): 역할을 학습으로 창발 ↔ 본 연구는 게임 규칙상 고정된 역할의 명시적 분리
- **포지셔닝: "BT+RL 최초 결합"이 아니라 — 제어권 분리 기준과 개입 구간 표본 처리 방법론이 기여**

## 슬라이드 11 — 계획된 평가 (진행 예정)

- **제거 실험 — 방법론 기여의 직접 검증 (최우선)**
  - 단순 혼합(BT 행동을 표본에 포함) vs Drop-only(보상까지 제거) vs 준마르코프 귀속(제안)
  - 지표: 승률·기믹 성공률·정책 엔트로피·가치 손실·수렴 속도, 다중 시드
- 동일 환경 순수 PPO 재학습 — 사전 실험을 엄밀한 대조군으로 격상
- 사용성 평가 — 실제 플레이어 대상
  - 규칙 기반 vs 하이브리드, 반복측정 설계(조건 교차 배치)
  - 역할 수행도·협동성·신뢰도·예측 가능성 리커트 측정 + 전투 로그 객관 지표와 상관 분석
- 전투 성능 가설은 비열등성, 기믹·학습 안정성은 우월성으로 설정

## 슬라이드 12 — 기여 요약 및 향후 일정

**기여 5가지:**
1. 실패 비용·판단 결정성 기반 규칙–학습 제어권 분리 설계 원칙
2. 실제 플레이 가능한 협동 보스 레이드 2계층 NPC 구현 (Unity + Python)
3. 규칙 개입 구간의 준마르코프 표본 수집 — on-policy 오염 처리
4. 제한된 결정론적 개입(22%)과 학습 다양성(78%) 양립의 정량 검증
5. 플레이어 성향 랜덤화를 통한 협동 강건성

**향후 일정:**
- 제거 실험·순수 PPO 대조군 학습 (파이프라인 준비 완료, 회당 ~10시간)
- 국내 학회(한국게임학회) 발표 → 제거 실험 결과 합쳐 국제 게임 AI 학회(IEEE CoG / AIIDE) 투고
- 사용성 평가 설계 및 IRB 검토

## (발표자 참고) 예상 질문 대비

- **Q. BT 턴을 그냥 버리면(Drop) 안 되나?** → 보상까지 버리면 BT가 만든 성과(기믹 성공 등)가 어떤 결정에도 귀속되지 않아 가치 추정이 편향됨. 그래서 제거 실험에 Drop-only 조건을 포함해 검증 예정.
- **Q. 순수 RL 비교가 왜 동일 환경이 아닌가?** → 사전 실험은 동일 계열 환경. 엄밀한 비교를 위해 현행 환경 재학습을 계획된 평가에 포함(한계 절에 명시).
- **Q. 승률이 규칙 기반보다 높지 않은데?** → 가설 자체가 비열등성. 기대 이점은 원시 승률이 아니라 미학습 조건 적응력과 인식된 협동 품질(사용성 평가 대상).
