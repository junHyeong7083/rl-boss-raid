# 연구계획 및 수행경과 (RA 신청서)

(Failure-Cost-Based Control Separation between Rules and Reinforcement Learning with Semi-Markov Learning for Cooperative Boss-Raid NPCs)

## 계획 및 경과

### 연구 배경 및 아이디어 (경과)

- MMORPG 보스 레이드의 파티원 NPC는 규칙 기반(FSM/행동 트리)으로는 상황 적응력이 떨어지고, 순수 강화학습으로는 "실패 시 즉시 전멸로 이어지는 저빈도 협동 기믹"(전멸기 은신, 낙인 산개 등)을 안정적으로 학습하지 못한다는 문제를 도출하였음.
- 사전 탐색 실험에서 순수 PPO 정책이 대규모 학습에도 기믹 수행을 안정화하지 못하고 학습 후반 정책 엔트로피 붕괴로 성능이 퇴행하는 현상을 관찰, 이를 근거로 본 연구 아이디어를 제안하였음 (아이디어 제안: 신청자 본인).
- 현재 관련 연구(하이브리드 게임 AI, 다중 에이전트 강화학습, 안전 강화학습의 실드 기법) 조사 및 연구 설계를 진행 중임.

### 연구 내용 (수행 계획)

1. **실패 비용 기반 제어권 분리 원칙 정립**: 보스 레이드 NPC의 행동을 "실패 비용"과 "판단 결정성" 두 기준으로 분류하여, 실패 비용이 극단적이고 정답이 명확한 필수 기믹은 행동 트리(제1계층)가 결정론적으로 보장하고, 맥락 의존적인 일반 전투 판단(포지셔닝·어그로·회복)은 역할별(탱커/힐러/서포터) 독립 PPO(제2계층)가 학습하도록 하는 2계층 협동 NPC 구조를 설계한다.
2. **준마르코프 표본 수집 기법 구현**: 행동 트리가 강화학습 정책의 제어권을 일시 대체한 턴을 on-policy 학습 표본에서 제외하되, 해당 구간의 할인 보상을 직전 강화학습 결정에 누적 귀속시키는 가변 길이 준마르코프 전이 방식을 구현하여, 규칙 개입에 의한 정책 경사 오염 문제를 처리한다.
3. **실험 환경 구축**: 실제 플레이어 1인(딜러)과 NPC 3인이 협동하는 자체 제작 보스 레이드 게임(Python 시뮬레이션 서버 + Unity 실시간 클라이언트, 보스 패턴 11종·무력화 게이지·축소 전장)을 구축한다.
4. **학습 파이프라인 구축**: 행동 복제 초기화, 보스 체력 3단계 커리큘럼, 플레이어 성향(공격형·안정형·미숙형) 도메인 랜덤화, 정책 엔트로피 감시를 결합한 학습 파이프라인을 구축하고 역할별 정책을 학습시킨다.
5. **비교·제거 실험**: (A) 규칙 기반 NPC, (B) 순수 PPO, (C) 제안 하이브리드에 더해, 규칙 개입 표본 처리 방식 3종(단순 혼합 / Drop-only / 준마르코프 귀속)의 제거 실험을 다중 시드로 수행하여 제안 기법의 기여를 정량 검증한다. 전투 성능 가설은 규칙 기반 대비 비열등성으로, 기믹 성공률·학습 안정성은 우월성으로 설정한다.
6. **사용성 평가**: 실제 플레이어를 대상으로 규칙 기반 NPC와 하이브리드 NPC를 반복측정 설계로 비교하여 역할 수행도·협동성·신뢰도·예측 가능성을 리커트 척도로 측정하고, 전투 로그 기반 객관 지표와의 상관을 분석한다.
7. **논문 작성 및 투고**: 결과를 종합하여 국내 학회 발표 및 국제 게임 AI 학회에 투고한다.

### 기대 성과

- 실패 비용 기반 규칙–학습 제어권 분리라는 게임 AI 설계 원칙 제시
- 규칙 개입 환경에서 on-policy 강화학습의 표본 일관성을 유지하는 준마르코프 학습 기법 검증
- 실제 플레이 가능한 협동 보스 레이드 게임 및 학습 파이프라인(공개 가능 산출물)
- 국내 학회 발표 1건, 국제 학회 논문 투고 1건
