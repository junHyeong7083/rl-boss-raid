# 설계: 검증 기반 제어권 이양 (Trust-Gated Control Handover)

> 작성: 2026-09-12 / 상태: **신규성 조사 조건부 통과 (2026-09-12) → 구현 착수**
>
> 조사 반영 사항:
> 1. 명칭·구조를 "행동별 면허 프로토콜(발급–감사–정지)"로 재정의 — ADVICE(2024, 전역 임계
>    비단조 조정)·Neural Simplex(2020, 복귀 전환)와 문장 수준에서 구분. "회수의 존재"는
>    신규성 주장 금지, "행동 단위 + 망각 유발 회수"로 한정.
> 2. 섀도(비집행) 평가는 협동 게임에서 원리적 불가(행동이 팀 결과를 인과적으로 바꿈) →
>    실집행 프로브가 유일한 추정 수단이고 프로브 비용이 실패 비용에 비례 — 이 논증을
>    명시적 기여로 승격 ("왜 게임 협동 NPC인가"의 답).
> 3. 이양/회수 임계는 LazyDAgger식 비대칭 히스테리시스, 프로브는 예산 제약(실패 비용
>    역비례 배분)으로 형식화. 망각 근거 문헌: Wolczyk et al., ICML 2024.
> 4. 투고 시장: 게임 AI 학회(CoG/AIIDE) — 안전 RL 학회는 ADVICE 차별화 부담으로 회피.
> 이 논문의 중심 문장(초안 — 저자 수정 예정):
> **"보장 계층이 행동별로 학습 정책의 신뢰도를 온라인 추적하여, 검증된 행동부터
> 제어권을 점진적으로 이양하고 성능 붕괴가 감지되면 회수하는,
> '스스로 물러나는 보장 계층'을 제안한다."**

## 1. 동기 (우리 실측에서 나온 필연성)

| 실측 근거 | 시사점 |
|---|---|
| M4: 무력화 집중은 RL이 유지 가능 | 일부 규칙은 물러나도 됨 — 정적 경계는 과보호 |
| M1: 전멸기는 1만 ep에도 학습 불가 | 일부 규칙은 영원히 물러나면 안 됨 — 임계는 행동별 |
| M2: BC로 획득된 산개를 RL이 재학습 중 상실 | **한 번 이양하면 끝(단조 완화)은 위험 — 감시·회수 필요** |
| M5: 어그로 규칙 승격 무해 | 회수(규칙 복귀)는 안전한 방향 |
| D: BT 행동 혼입 시 정책 붕괴 | 이양 판단은 표본 처리와 독립 계층에서 해야 함 |

## 2. 메커니즘

규칙 r마다 신뢰 점수 T_r ∈ [0,1] (초기 0).

1. **보호관찰(섀도) 평가**: 규칙 r이 발화할 상황에서 확률 ε_r = ε_max(r)·T_r … 이 아니라
   초기 탐색을 위해 ε_r = clip(ε₀ + k·T_r, 0, ε_max(r))로 RL 행동을 통과시키고,
   해당 상황의 결과를 규칙별 채점기로 채점:
   - seal_hide: 웨이브 폭발 시 안전 원 안 여부
   - brand_spread: 산개 성공(mechanic_success) 여부
   - imminent_escape: 텔레그래프 피격 여부
   - stagger_dps: 무력화 파괴 기여 여부
   - yellow_escape: 패링 장판 피격 여부
2. **신뢰 갱신 (비대칭)**: 성공 T += α(1-T), 실패 T -= β·T, β ≫ α (안전 우선).
   맥락 조건화(후보 2 예고편): T_{r,c} — c = 플레이어 성향 버킷.
3. **이양**: T_r ≥ θ_hand(r) 이면 규칙 침묵(완전 이양). 침묵 중에도 결과는 계속 채점(수동 감시).
4. **회수**: T_r < θ_recall(r) (θ_recall < θ_hand, 히스테리시스) 이면 규칙 복귀.
   → M2형 망각을 자동 감지·복구하는 장치.
5. **실패 비용 연동**: ε_max(r), θ_hand(r)를 행동의 실패 비용에 반비례/비례 설정.
   전멸기(즉사·동시성공)는 ε_max=0 (영구 보장) — 프레임워크의 실패 비용 축이
   장식이 아니라 파라미터가 됨. 경계 지도(M1~M5)가 임계 설정의 실증 근거.

표본 처리: 이양·보호관찰 턴은 RL 턴(정책 표본), 규칙 발화 턴은 기존대로 마스킹+SMDP 귀속.
보상: 이양 대상 규칙의 기믹 보상 그룹은 학습 시작부터 활성(M 실험에서 무해 확인).

## 3. 실험 설계

| 조건 | 내용 | 예산 |
|---|---|---|
| A-fix | 고정 BT (현행 기준선) | 기존 C 재사용 or 재학습 |
| A-adapt | 제안: 적응 이양 | 신규 20k |
| A-none | BT 없음 (순수 RL + 기믹 보상) | 신규 10~20k |
| (A-mono) | 이양만 있고 회수 없음 (단조 완화) — 회수의 기여 분리 | 신규 10k |

핵심 지표·그림:
- **신뢰 궤적 그림**: 행동별 T_r(t) — 무엇이 언제 이양되고, 무엇이 회수되는가 (대표 figure)
- 개입률(t) 감소 곡선, 기믹 성공률 유지 여부, 최종 승률
- A-mono vs A-adapt: M2형 망각 구간에서 회수가 성능을 지키는가 (핵심 ablation)
- 성향별 개입률 (후보 2 예고편): 미숙형 파트너에서 개입률이 높게 유지되는가 (창발 확인)

## 4. 구현 계획

- `bt_layer.py`: TrustGate 클래스 (T_r 상태, ε/θ 파라미터, 채점기 콜백, 발화 게이트)
- `env.py`: 규칙별 결과 채점 이벤트 (이미 있는 seal_holding/mechanic_*/damage_taken 재사용)
- `train_raid.py`: --bt-mode {fixed,adaptive,none,mono} 플래그, T_r 궤적을 metrics.jsonl 에 기록
- config: 실패 비용 등급표 (rule → ε_max, θ_hand, θ_recall)

## 5. 논문 재배치

- 제안 = 이 메커니즘. 기존 결과의 역할: M1~M5 = 정적 경계의 한계 + 임계 근거,
  D/E/F = 표본 처리 채택 근거 (각 한 절로 축약)
- 전작 연계: 전작 = 플레이어에 적응하는 NPC → 본작 = 자기 정책의 신뢰에 적응하는 보장 계층
  → 차기(학위논문) = 파트너 조건부 신뢰(T_{r,c}) 통합
